# 方案一：STM32 + HLK-RM58S 分体版（网络与控制彻底分离，零干扰）

### 一、核心硬件组成（固定必贴）

- 主控：STM32F407（自带原生MAC以太网控制器，时序最稳）
- 无线通信：HLK-RM58S 双频WiFi模块（串口AT通信，专门接收MQTT指令）
- 以太网外设：LAN8720A + RJ45网口（原生硬件以太网，专职发送WOL唤醒包）
- 基础供电：板载5V输入供电电路，整机统一供电

### 二、可选拓展外设（按需焊接，不用可不贴）

- DHT11温湿度传感器
- 隔离光耦触摸模拟电路（适配电容触摸台灯）
- 板载电容触摸按键模块（本地手动控制）

### 三、硬件工作链路

MQTT远程指令 → HLK-RM58S WiFi串口上报 → STM32主控解析指令 → 两路独立执行

1. WOL开机：STM32原生ETH+LAN8720 直接发送有线唤醒魔术包
2. 智能家居控制：主控IO驱动光耦/触摸模块/DHT11，完成灯光、温湿度采集

### 四、硬件结构特点

- WiFi网络、以太网、本地IO控制三层完全硬件隔离，无线射频绝不干扰灯光长按调光时序
    
- 原生硬件网口，WOL唤醒成功率100%，无SPI总线延迟
    
- 双芯片架构：WiFi只管收消息，STM32只管控制和有线网络，分工明确

# 方案二：ESP32-S3 单芯片一体化版（极简单板、低功耗、免双芯片）

### 一、核心硬件组成（固定必贴）

- 主控：ESP32-S3-WROOM-1（内置原生WiFi，直接跑MQTT客户端，无需外置WiFi模组）
    
- 以太网外设：W5500 + RJ45网口（SPI外接有线网卡，独立有线网口做WOL唤醒）
    
- 基础供电：板载5V输入供电电路，和方案一供电完全兼容
    

### 二、可选拓展外设（和方案一完全兼容，引脚定义一致）

- DHT11温湿度传感器
    
- 隔离光耦触摸模拟电路（同款台灯控制电路通用）
    
- 板载电容触摸按键模块（本地手动控制）
    

### 三、硬件工作链路

MQTT远程指令 → ESP32-S3内置WiFi直接接收解析 → 本地一站式处理

1. WOL开机：ESP32-S3通过SPI驱动W5500有线网口，发送唤醒包
    
2. 智能家居控制：片上GPIO直接驱动所有外设，单芯片完成全部功能
    

### 四、硬件结构特点

- 单芯片极简设计，无串口透传、无双芯片通信，PCB布线极简
    
- 整机功耗远低于分体方案，24h弱电箱长期运行发热量极低
    
- 自带OTA远程升级，整机固件一键更新，无需维护双程序
